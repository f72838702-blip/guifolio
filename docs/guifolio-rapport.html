1. Synthèse exécutive

Guifolio transforme un CV PDF en carte de visite digitale (pseudo.guifolio.com) avec bouton WhatsApp, ciblant la Guinée et l'Afrique de l'Ouest, monétisé par Mobile Money (Orange Money / MTN MoMo). Le MVP est construit et déployé (Next.js 16 + Supabase + extraction IA GLM/Kimi + ISR sous-domaines wildcard).

Constat OSINT principal : le marché mondial du "link-in-bio / portfolio" est saturé (Linktree, Carrd, Bento, Beacons…), mais aucun acteur ne couvre spécifiquement la Guinée avec triptyque IA + Mobile Money + français/WhatsApp-first. En Afrique de l'Ouest, les concurrents pertinents sont SIMOON CV (CV par IA), EKAA (carte de visite digitale NFC/QR), Fenzo / AfreeLink / 2Krika (marketplaces freelance). Guifolio occupe un intersect unique : génération de portfolio par IA, hébergé sur sous-domaine, payé en GNF par OM/MTN.

2. Comment fonctionne une telle plateforme

2.1 Architecture technique actuelle

  • Frontend/back : Next.js 16 App Router (TypeScript, Tailwind v4), hébergé Vercel Hobby (0 $). Pages publiques rendues en ISR (régénérées toutes les 60 s) → coût serveur quasi nul.
  • Sous-domaines wildcard : DNS *.guifolio.com → le middleware Next.js détecte pseudo.guifolio.com et réécrit invisiblement vers /p/pseudo. Un seul projet Vercel sert ainsi des milliers de portfolios.
  • Base de données : Supabase (PostgreSQL). Deux tables : portfolios (contenu JSONB, slug unique, plan, is_public) et transactions. Row Level Security : lecture publique des portfolios publics, écriture réservée au propriétaire, transactions écrites uniquement par la clé service (webhooks).
  • Auth : magic links Supabase (pas de mot de passe à gérer, adapté à un public peu tech).

2.2 Pipeline d'extraction IA (cœur du produit)

  1. L'utilisateur uploade son CV PDF (ou colle du texte) depuis le dashboard.
  2. /api/parse-cv extrait le texte du PDF (unpdf, max 5 Mo) — route protégée par auth.
  3. Le texte est envoyé à un LLM bon marché (GLM-4.5-Flash ou Kimi K3, API compatible OpenAI) avec un prompt d'extraction strict.
  4. La réponse JSON est validée par Zod (schéma PortfolioData : profil, contacts normalisés +224 / wa.me, compétences, expériences, réseaux sociaux).
  5. Le portfolio est pré-rempli → l'utilisateur corrige dans l'éditeur temps réel (Zustand, auto-save 1,2 s).

Coût unitaire IA : un CV ≈ 2–4k tokens → avec GLM-4.5-Flash (~0,11 $/M tokens), moins de 0,001 $ par CV. Marge quasi totale.

2.4 Boucle de croissance

  • Chaque portfolio FREE affiche le badge « Créé avec Guifolio » → chaque visiteur est un prospect.
  • Le partage WhatsApp du lien pseudo.guifolio.com est le canal naturel (CV envoyé aux recruteurs via WhatsApp = pratique déjà établie en Guinée).
  • QR code sur cartes de visite papier → pont physique → digital (Pro).

4. Ce qui reste à faire — roadmap complète

4.1 Blocage immédiat (sans ça, le site reste en mode aperçu)

P0 — Cette semaine :
  1. Créer le projet Supabase → exécuter supabase/schema.sql → activer le provider Email (magic links).
  2. Renseigner les variables d'environnement Vercel : NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_ANON_KEY, SUPABASE_SERVICE_ROLE_KEY.
  3. Clé LLM (GLM chez Zhipu ou Kimi/Moonshot) → LLM_API_KEY + LLM_BASE_URL/LLM_MODEL. Sans clé, l'extraction reste en mode mock.
  4. Activer l'auto-deploy Git→Vercel (le premier push n'a pas déclenché de build ; brancher GitHub dans le dashboard Vercel).

4.2 Paiements en production

P1 :
  1. KYC marchand chez Chap Chap Pay (registre de commerce + CNI, validation 24–48 h) ou compte créateur Chariow.
  2. Brancher /api/payments/initiate sur l'API choisie (le code existe, mode démo actuel = succès simulé).
  3. Configurer l'URL du webhook /api/payments/webhook + secret HMAC côté agrégateur.
  4. Tester en conditions réelles avec son propre numéro OM/MTN (petit montant).

4.3 Domaine & distribution

P1–P2 :
  1. Acheter guifolio.com (~10–15 $/an) et configurer le DNS wildcard *.guifolio.com dans Vercel.
  2. Créer la page de destination du badge « Créé avec Guifolio » (viral loop).
  3. OG images dynamiques par portfolio (opengraph-image Next.js) pour de beaux aperçus WhatsApp/Facebook — levier viral majeur.

4.4 Produit — features promises par les plans

P2 (débloquer la valeur PRO/VIP) :
  • QR code de la page (package qrcode, déjà fait dans waraba-basket) — plan PRO.
  • Compteur de visites (table page_views ou Simple Analytics/Plausible) — plan PRO.
  • Upload avatar vers Supabase Storage (au lieu d'URL manuelle).
  • Thèmes (2–3 variantes : light, gold, minimal) — plan VIP.
  • Domaine custom VIP : champ custom_domain + doc utilisateur (Vercel domains API).
  • Galerie photos / réalisations, CV PDF téléchargeable généré depuis les données, bouton « Partager » natif, formulaire de contact → message WhatsApp pré-rempli.

4.5 Robustesse & conformité

P2 :
  • Rate limiting sur /api/parse-cv (coût LLM) — ex. 10 extractions/jour/user (Upstash Ratelimit ou champ compteur).
  • Validation côté LLM : retry 1 fois si JSON invalide, timeout 30 s.
  • Pages légales : mentions légales, politique de confidentialité (données personnelles de CV !), CGV pour les paiements.
  • Migration middleware.ts → convention proxy (Next 16) : npx @next/codemod middleware-to-proxy.
  • Emails transactionnels (confirmation d'upgrade) via Supabase Auth templates ou Resend.
  • Monitoring : Vercel Analytics + Sentry (plan gratuit).

4.6 Go-to-market Guinée

P3 :
  • Cibler d'abord : étudiants en fin de cycle (UGLC, ESMT, universités Conakry), jeunes diplômés, freelances, commerçants Instagram/WhatsApp Business.
  • Distribution : groupes WhatsApp/Facebook d'emploi, ambassadeurs campus (modèle EKAA validé par OSINT), démo dans les incubateurs (Sabou Hub, etc.).
  • Offre lancement : Pro à 25 000 GNF les 3 premiers mois.
  • Contenu : tutos vidéo courts « Votre CV devient un site web en 2 min » (TikTok/Instagram, français).
  • Partenariats B2B : écoles (pack classe entière), cabinets RH, Fenzo/AfreeLink comme canal.

5. Risques & vigilances

  • Dépendance agrégateur : commissions + disponibilité OM/MTN ; mitiger plus tard par contrats opérateurs directs.
  • Arrivée d'un concurrent régional (SIMOON CV pourrait ajouter le portfolio web ; EKAA l'IA) — la vitesse d'occupation du marché guinéen est l'avantage défendable.
  • Données personnelles : le contenu de CV est sensible — is_public par défaut, droit à l'effacement, mentions légales obligatoires.
  • Pouvoir d'achat : 50 000 GNF/an ≈ 6 $ — juste au-dessus du prix psychologique ; rester flexible (promos, plan mensuel 5 000 GNF à tester).
  • Coût LLM : négligeable par CV, mais protéger l'endpoint (rate limit + auth) contre l'abus.
